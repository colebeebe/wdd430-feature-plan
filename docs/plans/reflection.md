# Feature Plan Reflection
## Which feature was the hardest to make testable?
I would say that the hardest were ones that were mostly (or purely) visual. I feel it's a lot easier to create testing criteria when you have a clear expected output, such as you would expect from a `GET` request, but with a visual element you can't really just say 'make it look good.'

## Where did AI repeatedly add scope you had to cut?
The AI really wanted there to be more features. It would either invent new ones or suggest that I create or add more.

## Which dependecy changed your implementation order?
For the most part, things worked out to be roughly how I expected them to be implemented, although something that was very useful was to think abou which ones could be implemented in tandem since they didn't overlap.

## What implementation risk did planning reveal early?
There were a lot of things that I hadn't considered, from very little things like missing images breaking page layout to much larger things like leaving orphaned reviews if the game is deleted.
